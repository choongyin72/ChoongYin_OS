## Top 5 Most Important Learnings

1. **ROBOT_CLAUDE.md governs all RF code generation** — place at EC project root. All future Robot Framework code generated by Claude Code must read this file first. It prevents the 10 most common mistakes automatically.

2. **Type Text (not Fill Text) for ALL EC PrimeFaces search fields** — applies to BOTH Playwright and Robot Framework. PrimeFaces triggers AJAX on keyup. Fill/fill bypasses keyboard events. This single rule prevents 80% of EC search-related test failures.

3. **JasperReports v7.0.3 breaks backward compatibility** — compiled `.jasper` files from v7.0.3 are incompatible with JasperReports 6.x runtime. EC 14.2.5 ships with 6.21.4. Deployment of v7.0.3 reports requires EC runtime upgrade. Flag for Grant/Woodside team.

4. **Auth state reuse saves significant CI time** — Playwright `storageState` (globalSetup.ts) and Robot Framework session persistence eliminate repeated Keycloak logins. For a 50-test suite, this saves 2-4 minutes per run.

5. **Local EC environment enables full runtime testing** — `https://ap-f0a7g341jn6d.corp.quorumsoftware.com:8443/` (sysadmin/Sysadmin) + `localhost:1521/ORCL` (ECKERNEL_EC/energy) are both available. All runtime testing should target local before COPS DEV.
