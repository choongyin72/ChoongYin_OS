## Help (description)
Stream sets are used to group streams together, e.g. for displaying certain streams together in one data screen. There are preconfigured stream sets that are used to link streams to a dedicated business function. New stream sets can also be made and used to group a set of streams for reporting purpose.

The stream set screen enables creation and editing of stream sets. Deletion of a stream set is not possible.
