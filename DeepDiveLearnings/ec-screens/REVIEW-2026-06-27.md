## 1. What this batch is about (EC domain learned)

The batch is mostly the **well / subsurface hierarchy and its allocation spine**, plus storage,
cargo/equity, and "Maintain X" admin screens.

### 1.1 The well object chain (the headline)
`WELL` -> `WELL_HOLE` -> `WELL_BORE` (WEBO_BORE) -> `WELL_BORE_INTERVAL` (WEBO_INTERVAL) — each an
**OBJECT / VERSIONED** master-data screen:

| BF | Screen | Backing | Class |
|----|--------|---------|-------|
| CO.0049 | Well | WELL | OBJECT/VERSIONED |
| CO.0051 | Well Hole | WELL_HOLE | OBJECT/VERSIONED |
| CO.0054 | Well Bore | WEBO_BORE | OBJECT/VERSIONED |
| CO.0057 | Well Bore Interval | WEBO_INTERVAL | OBJECT/VERSIONED |
| CO.0055 | Well Bore Split | WEBO_SPLIT_FACTOR | DATA/EVENT (phase split, sum=100%) |
| CO.0058 | Well Bore Interval Split | WEBO_INTERVAL_GOR | DATA/EVENT (phase split) |

The DATA/EVENT **split-factor** rows (CO.0055/0058) carry the bore/interval -> reservoir phase
allocation that sums to 100% per phase. This is the allocation backbone of EC production.

**KEY CONNECTION to shipped work:** the *Perf Interval* member used in the just-completed Unit-Well
Setup (RC.0050) and Tract-Well Setup (RC.0057) IUD bundles sits at this **well-bore-interval** level.
So this hierarchy is the layer *beneath* the Royalty "Well Setup" screens — the deep-dive retroactively
explains what those screens were wiring together.

is uneven** and there are fixable capture bugs.

- **Partial (8):** CO.0039, CO.0049, CO.0050, CO.0051, CO.0055, CO.0058, CO.0067, CO.0069 (good business
