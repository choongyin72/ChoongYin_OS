 Calculation Design 

 Introduction 

 Quality calculations are easier to maintain, especially when multiple developers work on the same codebase. Following best practices ensures that anyone can pick up where another developer left off. These practices evolve over time, so we welcome your feedback on the current standards. 

 Purpose of These Pages 

 This documentation serves as a central reference for calculation design best practices as they are currently defined. Whether you&#8217;re a consultant implementing a new solution, an expert reviewing existing calculations, or a customer SME understanding the technical approach, these pages provide: 

 Standardized approaches that promote consistency across projects 

 Practical guidelines drawn from real-world implementations 

 Clear conventions that reduce ambiguity and improve collaboration 

 The Challenge with Legacy Examples 

 From EC 10.0 to EC 14.1, the product ships with calculations designed over 20 years ago. While these calculations work, they reflect outdated practices. New projects often use these as templates, inadvertently perpetuating old patterns. This creates a ripple effect: each project develops its own approach, leading to inconsistent implementations across the board. 

 A New Direction 

 Starting with EC 14.2.x/15.0.0, we&#8217;re taking a different approach: 

 Library Calculations - Reusable components designed for high compatibility across projects 

 Well Volume Allocation - A simplified example that demonstrates current best practices 

 Template Calculations - Ready-to-use starting points for projects that need custom solutions, complete with pre-defined variables, global sets, iterator examples, and local sets that follow established naming conventions 

 These resources give developers a solid foundation and clear guidance on how to structure their work. 

 The following pages will provide guidelines and best practices on calculation design and maintenance. 

 What&#8217;s Covered in These Pages 

 The following pages provide practical guidelines organized by topic. Use this overview to navigate directly to the sections most relevant to your work: 

 Naming Conventions 

 Naming conventions generic - Core principles for meaningful, consistent, and unambiguous naming 

 Naming Conventions Sets and Iterators - Detailed standards for sets (global, local, dynamic) and iterator abbreviations 

 Naming conventions variables - Guidelines for database variables, global variables, and local variables including dimension standards 

 Calculation Structure and Standards 

 Equation Blocks, Equation standards, and logging - Best practices for organizing and documenting calculation logic 

 Calculation Data Model Best Practices - Optimal approaches for data structure and performance 

 Library Calculations 

 Library Calculations - Overview of the library calculation framework and its benefits 

 Sets, Variables and Iterators for library calculations - Specific conventions for library calculation components 

 Library Calculation Design - Architectural patterns and design principles 

 Creating a New Library Calculation - Step-by-step guidance for building new library calculations 

 Library Calculation Basics - Fundamental concepts and usage patterns 

 Working with Library Calculations - Practical tips for implementing and maintaining library calculations
