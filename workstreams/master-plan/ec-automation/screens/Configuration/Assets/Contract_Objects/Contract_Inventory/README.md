# Contract Inventory - IUD automation bundle

**Screen:** Configuration > Assets > Contract_Objects > Contract Inventory (BF CO.2054).
**Type:** OV-GM (manage-object, groupmodel; grid `manageObject:form:T_data`),
**Business-Unit-gated navigator** (single-row, increasing-column shape; only Business Unit is
genuinely mandatory — Contract Area/Contract stay optional even after Business Unit is filled),
date-effective, versioned (`OV_CONTRACT_INVENTORY`).
**Delete:** End Date = Start Date (packed `objectdates` row - true delete from `OV_CONTRACT_INVENTORY`).
**Status:** live **5/5 PASS** (Area pattern, TC01-TC05), DB-verified, self-cleaning.
See [contract_inventory_sow.md](contract_inventory_sow.md) and [JOURNAL.md](JOURNAL.md).

## Key facts
- Navigator: single group (`G:0`), single row (`R:1`), increasing column - `nav:form:G:0:R:1:C:1:dd`
  = Business Unit is mandatory + GO; `C:2` Contract Area and `C:3` Contract stay optional even
  after Business Unit is filled (live mandatory-yellow DOM check, PR #556). Both Business Unit and
  Contract Area are still filled in `testdata/contract_inventory_navigator.properties` for parity
  with the already-proven prior scope, not because Contract Area is required. Fill goes through
  the shared T2 `Apply Navigator From Properties`, zero shared-file changes needed.
- Insert form (`objectForm`) mandatory: **Contract Inventory Code**, **Contract Inventory Name**,
  **Start Date** (in `objectdates`, not `objectForm`), plus a fixed "Contract name" dropdown =
  `TS5 Shipper C`.
- Delete `objectdates` End Date field id is hardcoded
  (`tab:tabPanel:objectdates:form:G:0:R:0:C:3:da_input`), not label-driven - Start Date/End Date
  share a packed row the one-field-per-row label scan cannot resolve safely (same rationale as
  Area's own del-enddate constant).
- The RF suite uses the FIXED test code `AUTOTEST_CONTRACT_INVENTORY` (not a per-run timestamp -
  since PR #556); the Playwright driver still uses the original `AUTOTEST_CI_<timestamp>` per run.
