## DB self-clean check (ground truth — OV_CHEM_STRM_HOOKUP)
Run BEFORE and AFTER the live suite, from a fresh connection each time (never reuse a mid-test
session), to confirm the fixed test code (`AUTOTEST_CSH`) is absent and no `AUTOTEST%` residual
rows exist (the screen's `OV_CHEM_STRM_HOOKUP` view uses the generic `CODE` column, same
convention as every other `OV_*` view — see `libraries/DbVerify.py`):
```sql
SELECT COUNT(*) FROM OV_CHEM_STRM_HOOKUP WHERE CODE = 'AUTOTEST_CSH';   -- expect 0
SELECT CODE FROM OV_CHEM_STRM_HOOKUP WHERE CODE LIKE 'AUTOTEST%';       -- expect no rows
```
PR #544's own body cites exactly this pattern: "Fresh oracledb connection ... confirmed
`AUTOTEST_CSH` free in `OV_CHEM_STRM_HOOKUP` before the run (count = 0)" and, after the run,
"`SELECT COUNT(*) FROM OV_CHEM_STRM_HOOKUP WHERE CODE LIKE 'AUTOTEST%'` = 0".
