# Workstream: Production Stability

Live system issues, UAT bugs, hotfixes, and architectural corrections for Woodside Pluto ECaaS.

## Triage levels
- **P1** — Production down or data incorrect for live users → hotfix branch immediately
- **P2** — UAT blocker → prioritise in current sprint
- **P3** — UAT issue, non-blocking → bundle into next wave delivery

- **ECSR-XXXXX** — support / bug tickets (Jira: energycomponents.atlassian.net)
- **ECPR-XXXXX** — change / feature tickets (used for fixes too)
