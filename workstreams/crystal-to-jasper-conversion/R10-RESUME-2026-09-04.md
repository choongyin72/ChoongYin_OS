## Defect classes that keep recurring — check these first on every remaining report

1. **The white-ring pen — found five times** (R10.006 section bars, R10.008 ×9, R10.009 ×19,
   R10.010's own `ColHeadStyle` band seams and ×8 info cells, R10.011 ×18).
   A `rectangle` whose style has `forecolor="#FFFFFF"` and whose `<pen>` has no `lineColor`
   outlines itself in **white**. Where the cell also holds text the style's box draws black over
   it, so it only shows on **empty** cells — which is why it hides. `r10_follow_original.py` now
   fixes it as a rule and a guard fails the build if one reappears.
2. **Inline `fontSize` / `bold` / `italic` on an element overrides its style.** Cost a round on
   R10.009 and again on R10.010. The pipeline strips them.
3. **Part F1** — a box shorter than `fontSize × 1.2` renders *nothing*, silently. 22 such
   elements are still outstanding in R10.030 (×2 files) and R10.031 (×2 files).
4. **Anchoring rows on repeated text collapses them.** `Date`, `Time`, a date value — each
   appears many times, and several rows then land on one y. Anchor only on text that occurs
   **once** on that page; interpolate the rest between anchors; snap purple bands to the
   original's own measured band tops.
5. **Value and unit columns touching** makes them one joined span (`174,000m3`,
   `89,610.00USD/Day`). The originals right-align values to a common edge and left-align units
   after a gap.
