## A real bug found while doing this, outside the layout

`r10_regen.py` chose each folder's data harness with `"SDS" in jrxml_name`. **Every**
R10.030/R10.031 stem contains the literal `ADP_SDS`, so the ADP variants were being filled by
`R10030SdsVerify` / `R10031SdsVerify` — a **different dataset** (`R10030Verify` row 1 is
`IC25-EX-01` with a null vessel; `R10030SdsVerify` row 1 is `IC25-IN-IN06` / `Oceanic Breeze`).
Five of the eight PDFs were being rendered with the wrong sample data. Fixed by resolving the
variant as the part of a stem its siblings do not share — the same fix as the reference pairing.

## Corrections to my own defect report

1. **"R10.029's rows sit ~130pt lower" and "R10.030's info block sits ~700pt too low" were
   wrong.** I mis-read my own stacked comparison image — the build panel starts partway down the
   PNG, and I did not subtract that offset. Measured properly, the row residuals are a median of
   **−0.9 to −1.1pt**. There was never a large vertical offset.
2. **"Not one of these has a `detail` band" was wrong** (already noted in the audit): six of the
   eight do. My grep used `<detail ` with a trailing space.
3. **My italic count was measuring the wrong attribute.** It grepped `isItalic="true"`, which is
   JasperReports' legacy element syntax; these files use `italic="true"` on the style. It
   reported 0 for all eight even after italic was applied and visibly rendering.

## A change I made, then reverted

I first fixed the header merge by growing only the span-both cells. That made R10.031 **worse** —
dropping the invented `Date`/`Port`/`Date` sub-cells also removed the navy they were painting,
so white gaps opened, and `Estimated Loading Date` / `Scheduled Unloading Date` clipped. The
clipping was not the merge: the accent pass had raised those captions to 9pt inside a 20pt cell,
where one line needs 10.8pt and two need 21.6, so the cell cannot wrap and cuts the text at the
edge. I reverted all six from backup and rebuilt the whole block to the original's row split
(49pt block / 35pt top / 13pt bottom), which is the room the wrap needs. The captions now wrap.
